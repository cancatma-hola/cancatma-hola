# Videolar

| Klasör | İçerik | Biçim |
|---|---|---|
| `egitim/` | Eğitim videoları: panelin her ekranı adım adım | yatay + dikey |
| `tanitim/` | Tanıtım ve promo videoları (00 = hype promo) | yatay + dikey (00 yalnız yatay) |
| `ilk-seri/` | İlk üretilen eğitim (E) ve süreç (V) videoları | yatay + `.srt` altyazı |
| `arsiv/` | İlk hype promo ve stil denemeleri | yatay |

Dosya adı: `<tür>-<no>-<konu>-<yatay|dikey>.mp4`
- **yatay** 1920×1080: web sitesi, YouTube, sunum
- **dikey** 1080×1920: Reels, Shorts, TikTok, WhatsApp durum

Tüm videoların başlık, süre ve ekrandaki metinleri: [`../08-video-katalogu.md`](../08-video-katalogu.md)
